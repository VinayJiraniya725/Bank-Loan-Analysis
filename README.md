
# 🏦 Bank Loan Analysis

## 📌 Project Overview

The **Bank Loan Analysis** project focuses on analyzing loan application data to understand loan performance, funded amounts, repayment amounts, customer and loan characteristics, and regional trends.

The project uses **Python and data visualization techniques** to perform Exploratory Data Analysis (EDA) and generate meaningful insights from the loan dataset.

---

## 🎯 Project Objective

The main objective of this project is to analyze bank loan data and understand:

* Loan application performance
* Total funded and received amounts
* Good and bad loan performance
* Monthly loan trends
* Regional loan distribution
* Loan terms and employment length
* Loan purposes
* Home ownership patterns
* Average interest rate and Debt-to-Income ratio (DTI)

## 📈 Monthly Trend Analysis

Monthly analysis was performed using the loan issue date to understand changes over time.

The project analyzes:

* Total Funded Amount by Month
* Total Amount Received by Month
* Total Loan Applications by Month

Line and area charts are used to make monthly trends easier to understand.

---

## 🌎 Regional Analysis

The project analyzes loan funding across different states.

### Analysis Performed

* Total Funded Amount by State
* State-wise comparison of funded amounts

A horizontal bar chart is used to visualize the regional distribution of loan funding.
